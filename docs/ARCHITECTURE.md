# 架构说明

## 1. 系统目标

本项目服务于一台基于二维激光雷达和轮编码器的差分小车，目标是在未知环境中完成：

- 建图与定位
- 自主探索
- 局部避障与路径跟随
- 实机 / 仿真 / 离线回放三种运行模式切换

## 2. 运行链路

### 2.1 数据入口

- 仿真模式：`robot.py` + `lidar.py`
- 实机模式：`bluetooth_connection.py` + `real_robot_bridge.py`
- 回放模式：`main.py` 中的 `RecordedScanPlayer`

### 2.2 感知与定位

1. 获取一帧激光扫描和一段运动增量。
2. `noise_filter.py` 可选地对激光和里程计做预处理。
3. `icp_slam.py` 用运动先验初始化当前位姿，再将当前扫描和地图点云做 ICP 匹配。
4. 将匹配后的障碍点写回占据栅格与全局点云。

### 2.3 全局探索

1. `frontier_explorer.py` 在已知空闲区域边界寻找前沿点。
2. 当前沿很多时，先做聚类和缓存，减少重复规划。
3. `fast_path_planner.py` 按距离在 BFS、双向 BFS 和优化 A* 之间切换。

### 2.4 局部控制

1. `dwa.py` 读取当前位姿、目标点和局部障碍。
2. 在动态窗口内采样速度对。
3. 综合目标方向、终点距离、障碍、旋转、进度和倒车约束打分。
4. 输出平滑后的 `(v, w)` 控制，并在实机模式下通过桥接模块发送电机命令。

### 2.5 可视化与导出

- `visualizer.py` 提供基础 Matplotlib 可视化。
- `async_visualizer.py`、`multiprocess_visualizer.py`、`shm_visualizer.py` 分别对应线程、多进程和共享内存版本。
- 支持导出地图、轨迹以及若干性能分析图。

## 3. 关键模块分工

| 模块 | 职责 |
| --- | --- |
| `main.py` | 系统编排、状态机、模式切换、主循环 |
| `maze_loader.py` | 读取地图配置，生成墙体与占据栅格画布 |
| `robot.py` | 差分机器人运动学与仿真积分 |
| `lidar.py` | 2D 激光模拟 |
| `icp_slam.py` | ICP 建图定位、点云维护、地图更新 |
| `frontier_explorer.py` | Frontier 检测、缓存、聚类、目标选择 |
| `fast_path_planner.py` | 栅格路径规划 |
| `dwa.py` | 局部规划与避障控制 |
| `real_robot_bridge.py` | 把 BLE 数据适配成导航栈可用接口 |
| `bluetooth_connection.py` | BLE 连接、通知解析、数据落盘 |

## 4. 核心算法细节

### 4.1 ICP SLAM

- 输入：上一时刻位姿、当前扫描、运动增量
- 先用运动增量做预测
- 再在全局地图点云上做配准
- 对配准结果施加收敛阈值和修正上限
- 最后更新点云和占据栅格

这样做的优点是：

- 运动先验能缩小 ICP 搜索范围
- 地图点云持续累积，适合未知环境探索
- 代码支持 CPU / CUDA / Apple MPS 多种后端

### 4.2 Frontier 探索

前沿定义为：

- 当前为空闲格
- 邻接未知格

策略上分为两层：

- 局部 BFS：优先快速找到近处可达前沿
- 全局回退：必要时扫描全图、做聚类和重新规划

### 4.3 DWA 局部规划

`dwa.py` 不是教材版最小实现，而是针对真实小车做了大量工程化增强：

- 速度平滑
- 近墙偏置
- 原地旋转策略
- 倒车抑制与振荡检测
- 制动上界
- 路径切向提示

因此它既承担“局部避障”，也承担“把全局路径变成可执行控制”的职责。

## 5. 设计取舍

- 没有做完整包化：优先保持课程项目原有脚本入口和相对路径稳定。
- 文档与历史分析笔记分离：README 面向首次阅读者，`docs/notes/` 保留调参与优化过程。
- 公开仓库默认不启用实机 BLE：避免未配置硬件时直接报错，也避免暴露设备地址。
